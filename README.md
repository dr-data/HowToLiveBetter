# 高性價比人生指南

講怎麼活得久、怎麼少生病，出了意外怎麼救。講怎麼少花冤枉錢，哪些事會讓人被騙、攤上官司。講沒工作沒錢時能去領什麼，開店、開公司、做網站要辦什麼手續。也講戀愛結婚生孩子、出國和學手藝。法律、醫療、強積金與社會保障等制度內容，以香港特別行政區現行法例與政策為準，並保留全球通用的醫學與科學實證。<br>
765 條建議，每條寫明花掉什麼、換回什麼、證據有多硬，來源只引期刊論文和官方文件，少數官方不公開的案件引署名的原創新聞報道並附網頁存檔。

不用全做：這是一份備選單，不是任務清單——挑走一兩條就算數，作者自己也沒做到其中大部分。

書裡的內容可能過時，也可能有錯。不少政策各地執行不一樣。真去辦事、看病、打官司時，以當地部門、醫生和律師的說法為準。發現寫錯了，歡迎[提 issue](https://github.com/dr-data/HowToLiveBetter/issues)。

## 怎麼讀

- **不用全做**：這是一份備選單，不是任務清單。挑走一兩條就算數，剩下的放著，需要時再回來查。「說著容易做著難」這個評價是對的——作者自己也沒做到其中大部分，寫下來是為了要用的時候找得到。想挑省力的，看下面「只想看最值得做的」那條。
- **想讓 AI 幫你查**：倉庫裡帶了一箇中文 skill（[skills/life-decision-guide](skills/life-decision-guide/)），Claude Code 和 Codex 都能裝。裝上以後直接問「替朋友擔保籤不籤」「每天通勤兩小時值不值」。它會先把相關條目從正文裡查出來，再照書裡的算賬方式排序回答，並註明出自第幾節第幾條。查不到就說查不到，不自己編數字。裝法見 [那個目錄的說明](skills/life-decision-guide/README.md)。
- **想按條件挑**：打開[在線檢索頁](https://dr-data.github.io/HowToLiveBetter/)，可以按關鍵詞、章節、證據等級來篩，也可以按「花不花錢、花多少時間、要不要毅力」這三樣篩，幾個條件能疊著用。頁面上的內容直接取自 book/ 目錄裡的正文，正文一改，頁面跟著改。
- **條目之間會互相指路**（「見第 8 節第 17 條」這種）：在檢索頁裡，這種指路帶一條虛線。點一下，就地顯示被指的那條的標題和「說人話」。想真的翻過去，再按「跳過去」。那一條正好被篩選條件藏起來了，頁面會自動把篩選清掉。在 GitHub 上直接讀正文點不動，但每處指路後面都寫著指向什麼（「見第 18 條（借錢寫清借條）」）。不翻過去也知道說的是哪條。
- **想按順序讀**：每節內的先後順序不代表性價比高低。條目多的節開頭有一段分組導覽，按主題挑著看就行。
- **想離線看、想發給別人**：下載 [離線單文件 HTML](https://github.com/dr-data/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.html)，整本書連同檢索和篩選都在這一個文件裡，雙擊就開，不用服務器也不用聯網，微信裡也能直接傳。
- **想打印或在手機上翻**：下載 [PDF](https://github.com/dr-data/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.pdf)，A4 排版、兩百多頁，帶目錄頁碼和書籤，每節另起一頁。
- **想在 Kindle 或其他閱讀器上讀**：下載 [EPUB 電子書](https://github.com/dr-data/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.epub)，Kindle 用 Send to Kindle 發過去即可。
- **想記住、隔幾天複習一遍**：下載 [Anki 牌組](https://github.com/dr-data/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.apkg)，用 Anki 打開就導入。一條一張卡，按節分成子牌組。正面是建議，背面是說人話、成本和證據等級。可以只學其中幾節，也可以按「性價比極高」這類標籤篩。以後重新下載再導入一次，卡片內容會更新，複習記錄不丟。
- **這四樣都是正文每次更新後自動重新生成的**，下載鏈接固定不變；轉發出去的那一份不會跟著更新，以在線版為準。
- **看不懂那串數字**：每條都有一行「說人話」。它把「收益」欄裡那些研究裡的寫法，翻成「同期死亡的概率低約兩成」「拘留幾日、罰多少錢」這樣的日常說法。它只用「收益」欄已經寫到的內容，不添新數字。只看這一行就夠拿主意。「收益」欄裡原樣留著全部數字，想自己核對就看那一欄。
- **只想看結論最硬的**：在檢索頁裡勾選證據等級 A，只留下有具體數字、來自薈萃分析或大型試驗的 524 條。
- **只想看最值得做的**：勾選性價比「極高」，得到 122 條不花錢、用時少、不需要毅力，收益又落在最大一檔的條目。再疊加一個「換回什麼」，就是該口徑下的優先清單。
- **看到「不要」開頭的節標題不用緊張**：節標題說的是這一節想防住的事（不要早死、不要浪費時間），不是說底下每條都在讓你別幹什麼。真正要做的動作寫在條目標題裡，一律動詞開頭，自己就寫清了是「做什麼」還是「別做什麼」。同一節裡兩種都有：第 4 節既有「把『打算做』寫成『幾點、在哪、遇到什麼就做什麼』」，也有「不看電視和滾動新聞」。按條目標題讀，不用往節標題的語氣上套。

每條建議長這樣：

```markdown
### 5. 把家裡的食鹽換成低鈉鹽（鉀鹽）
- 成本：一袋比普通鹽貴幾元。買的時候順手換，不額外佔時間。口味幾乎不變。
- 說人話：得過中風或 60 歲以上有高血壓的人，把家裡的鹽換成低鈉鹽，五年內死亡的概率低約 12%，中風低約 14%。
- 收益：一項把人隨機分成兩組的試驗，在中國農村做的，20995 人，都是得過卒中的人或者 60 歲以上的高血壓病人，跟蹤了 4.74 年。結果：用低鈉鹽的那組比用普通鹽的那組，死亡風險低約 12%（RR 0.88）。卒中低約 14%（RR 0.86）。主要心血管事件低約 13%（RR 0.87）。
- 證據等級：A
- 來源：Neal B 等 (2021). Effect of Salt Substitution on Cardiovascular Events and Death. NEJM. https://doi.org/10.1056/NEJMoa2105675
- 備註：爭議。試驗對象是高危老人，健康年輕人換鹽得到的好處要小得多。腎功能不全的人，或者正在吃保鉀類藥物的人，換鹽前先問醫生。
```

## 四種資源

這本書想幫你多留住的不只是壽命，一共四樣東西：

- **壽命**：活得更久，少死於本來可以避免的事
- **時間與精力**：活著的時間不花在沒有回報的事上，每天的注意力和體力少被白白耗掉
- **金錢**：少花冤枉錢，把錢花在收益確定的地方
- **人身自由**：不因為不知道一條紅線，把自己送進拘留所或者看守所

每一條建議都回答兩個問題：要花掉什麼（錢/時間/精力/毅力），能換回什麼（總死亡率變化 / 特定死因下降 / 時間與精力節省 / 金錢節省 / 保障與人身自由）。每條的性價比檔由檢索頁按收益大小和三項成本算出來，想挑划算的就按它篩選。

**一條建議的好處落在誰身上，是分檔的。** 按「這份好處將來有多大可能回到你自己身上」從高到低：① **你自己**；② **配偶和直系親屬**（父母、子女、祖父母外祖父母、孫子女外孫子女）；③ **朋友、同事和其他親屬**——互惠關係，幫出去的將來可能回來；④ **陌生人**——最低一檔，但不是零：回報的概率小，而且你不瞭解對方性格，還有被訛、被反咬、被報復的一面。不同檔不合並計算，寫到第 ④ 檔時好處和風險一起寫。

急救那一節照這個讀：中國 38,227 例院外心臟驟停裡 79.2% 發生在家裡，學按壓首先是為了按在自家人身上；「看到有人溺水自己不下水」「撞見鬥毆別上手拉架」這類規則本身就是自保規則，防的是你從旁觀者變成第二個傷者。對陌生人要不要出手是你自己的權衡，條目會把免責條款、自保動作和風險面都寫清楚，不替你把它算成非做不可的理由。

死亡率的數字、時間精力的數字、金錢的數字和法律後果，各算各的，不互相折算。這四樣對應檢索頁上那四個「換回什麼」，彼此之間不比大小。

## 證據分級

每條建議都標註證據等級：

| 等級 | 含義 |
| --- | --- |
| A | 有具體數字可查，出處是多項研究合併起來的薈萃分析、跟蹤很多人很多年的大型隊列，或者隨機分組的試驗（RCT），能說出降了多少（HR、RR、下降百分比） |
| B | 有研究支持，但說不出一個確切數字；或者只有小樣本、單獨一項研究撐著 |
| C | 作者自己的經驗，或者大家公認的做法，沒有直接的研究文獻 |

全書 765 條中 A 級 524 條、B 級 210 條、C 級 31 條，另有 85 條標註了爭議、0 處標註了 TODO 待核實。有爭議的 A/B 級條目會標註「爭議」並列出反方證據。所有來源只引原始文獻（期刊論文附 DOI 或 PubMed 鏈接，或 WHO/CDC/國家統計局等官方機構報告），不引二手轉述。官方不公開的案件，少數條目引了有記者署名的原創新聞報道，只用來說明「發生過這類事」，來源欄附網頁存檔，備註寫明「只有媒體報道」。不確定的數字標「待核實」。

A 級只說明「有具體數字、出處可核」，不說明這個數字一定是因果。A 級裡既有隨機分組的試驗，也有隻跟蹤記錄、不分組的研究，後者分不清是這件事起了作用，還是做這件事的人本來就更健康。哪一種看收益欄：寫著「隨機分成兩組」的是前者，寫著「只記錄、不分組」的是後者。法律和政策類條目的 A 級，指的是引到了法條或官方文件原文。

收益欄和說人話裡的百分比，多數是比沒做的人低幾成，不是每一百人裡少幾個。同樣低 12%，本來風險就高的老人少掉的死亡人數，遠多於本來風險就很低的年輕人。所以先看說人話裡寫的是哪些人，再看那個百分比。

## 性價比檔

證據等級只回答「這個數字可不可信」，不回答「這件事值不值得做」。所以每條還另外標了兩樣：收益量級（好處有多大）和口徑（換回的是哪一類東西）。檢索頁拿這兩樣加上三項成本，合出一個性價比檔：

| 維度 | 取值 | 怎麼定的 |
| --- | --- | --- |
| 口徑 | 換壽命 / 換錢 / 換時間精力 / 換人身自由 | 看這條主要換回的是什麼。**不同口徑之間不做比較**，「總死亡率降 12%」和「每年省 500 元」不在一把尺子上，沒法分高下 |
| 收益量級 | 大 / 中 / 小 | 儘量照著條目自己的「收益」欄，按事先定好的界線套，不憑感覺：換壽命看降了百分之幾（≥20% 為大，10–20% 為中，<10%、或者只量到中間指標而沒量到最終結果的為小）；換錢看金額（萬元級為大，數百到數千為中，幾十元為小）；換人身自由看後果（避免刑事責任為大，避免拘留或行政處罰為中，避免民事糾紛為小）；換時間精力看省下多少（每天省出小時級為大，每週小時級為中，只省一次的為小） |
| 性價比 | 極高 / 高 / 一般 | 好處大、三項成本都在最低檔 = 極高；好處大、成本不高，或者好處中等、三項成本都在最低檔 = 高；剩下的 = 一般 |

三項成本的最低檔是「不花錢、用時少、不需要毅力」。「用時少」指一次花幾分鐘以內，或順手就能做。

全書 765 條中性價比極高 122 條（16%）、高 346 條（45%）、一般 297 條（39%）。中間那檔條數多是有意的：底下的收益量級本來就只分大、中、小三級，再往細裡切就是裝出來的精確。

**這一檔是作者自己的判斷，不是證據**，按本書的標準它本身只算 C 級；它和證據等級是兩回事，誰也不影響誰。一條可以證據是 A 級、性價比卻只算一般（帶狀皰疹疫苗有 97.2% 效力的三期 RCT，但兩針三四千元、帶狀皰疹很少致命），也可以證據只有 C 級、性價比卻極高（手機設鎖屏密碼、SIM 卡設 PIN 碼）。「一般」不等於不該做——全書的條目都是建議做的，只是這一檔得你自己掂量那筆花銷值不值。

## 讀懂數字（術語表）

正文儘量用日常說法，但引用研究的時候免不了出現幾個統計名詞。看不懂就查這張表；在線檢索頁裡，把鼠標停在帶虛線的詞上（手機上點一下）也會彈出解釋。

<details>
<summary>展開 41 條術語（總死亡率、HR、RR、95% CI、薈萃分析、BMI、LPR、定金與訂金……）</summary>

| 術語 | 意思 |
| --- | --- |
| 總死亡率 | 一段時間裡，一群人當中死掉的人佔多大比例，不管死於什麼原因。本書用它衡量「活得久不久」。研究原文裡叫全因死亡率，英文縮寫 ACM |
| HR | 風險比。同樣一段時間裡，做了某件事的那組人出事（死亡、得病）的快慢，除以沒做的那組。HR 0.87 就是比沒做的那組低 13%，HR 1.21 就是高 21% |
| RR | 相對風險。兩組人出事的可能性之比，數字怎麼讀和 HR 一樣 |
| OR | 比值比。也是兩組的對比，只是算法和 RR 略有不同：要比的那件事很少見時，它和 RR 差不多；那件事很常見時，它會把差距說得比實際大 |
| IRR | 發病率之比。發病率是一段時間裡新得這個病的人佔多大比例，兩組相除，讀法同 RR |
| RaR | 發生次數之比。比的是事情發生了多少次（比如摔了多少跤），不是多少人出事，讀法同 RR |
| 標準化死亡比 | 英文縮寫 SMR。這群人實際死了多少人，除以「同樣年齡的普通人本該死多少人」。5.86 就是死的人數是同齡人的 5.86 倍 |
| 風險差 | 兩組出事的概率相減，直接得出「每一千人裡多出幾個」。倍數只說翻了幾倍，風險差說的是實實在在多了多少人 |
| 95% CI | 95% 置信區間。研究算出的數字總有誤差，這是真實情況很可能落在的範圍。倍數類的數字，範圍跨過了 1；加減類的數字，範圍跨過了 0，就說明兩組的差別可能只是碰巧，文中會寫「無統計學意義」 |
| RCT | 隨機對照試驗。用抽籤一樣的辦法把人分成兩組，一組做這件事，一組不做，過後比結果差多少。要證明「是這件事起了作用」，這種做法最有說服力 |
| 薈萃分析 | 把很多項研究的結果湊到一起重新算，得出一個總的數字。也叫 meta 分析 |
| 隊列 | 隊列研究。挑一大群人跟蹤很多年，記錄誰出了事。能看出兩件事常一起出現，但不足以證明是前一件造成了後一件 |
| 觀察性 | 觀察性研究。研究者只在旁邊記錄，不安排誰做、誰不做。結果容易被別的因素帶偏（見本表的混雜、反向因果兩條），數字要打點折看 |
| 混雜 | 有第三個因素同時牽動著前因和後果，讓兩件事看起來像有因果。比如愛吃菜的人往往也更愛運動，分不清是哪一樣在起作用 |
| 反向因果 | 因果的方向弄反了：看著像前一件引起後一件，其實是後一件引起前一件。不是睡得多讓人早死，而是病重的人睡得多 |
| d、g | 效應量，表示兩組的差距有多大。把差距換算成「相當於幾倍的常見波動幅度」：0.2 算小，0.5 中等，0.8 大 |
| r | 相關係數。兩件事跟著一起變的緊密程度，取值從 -1 到 1，0.1 算弱、0.3 中等、0.5 算強 |
| MET | 運動強度的單位。安靜坐著是 1 MET，快走約 3 到 4 MET。寫成 MET·h，就是強度乘以做了幾小時，表示一共動了多少 |
| GRADE | 國際上通用的一套打分辦法，給一項證據有多可靠評級，分高、中、低、極低四檔 |
| 意向篩查分析 | 算效果時按「通知了誰去做篩查」算，不按「誰真的去做了」算。被通知的人裡總有沒去的，所以這種算法會把篩查對真去做的人的好處算低 |
| 包年 | 統計一個人一共抽了多少煙的單位。每天抽幾包乘以抽了幾年，30 包年就是每天一包抽了 30 年 |
| BMI | 體重指數，看胖瘦常用的一個數：體重的公斤數，除以身高米數的平方 |
| LDL | 低密度脂蛋白膽固醇，俗稱壞膽固醇 |
| eGFR | 估算腎小球濾過率，衡量腎臟過濾能力的一項指標，單位 mL/min/1.73 m²。數越低說明腎功能越差，慢性腎病分幾期就按它定 |
| HBsAg | 乙肝表面抗原，化驗單上的一項。結果是陽性，表示已經感染了乙肝病毒 |
| HPV | 人乳頭瘤病毒。它分很多型，其中一部分型長期感染會導致宮頸癌 |
| LDCT | 低劑量胸部 CT，輻射量約為普通 CT 的五分之一到十分之一 |
| PM2.5 | 飄在空氣裡的細顆粒物，直徑在 2.5 微米以下 |
| NOVA | 一種給食品分類的辦法，按加工得有多厲害分成四類，「超加工食品」就是其中的第四類 |
| LPR | 貸款市場報價利率。國內貸款利率的基準，每月 20 日公佈一次，房貸利率和民間借貸的利息上限都照著它算 |
| 一裁終局 | 勞動仲裁的結果下來就直接生效，單位不能再拿這件事去法院起訴 |
| 粗結婚率、粗離婚率 | 每一千人裡，當年登記結婚、登記離婚的對數。另外還有個數叫離結比，是當年離婚對數除以結婚對數，和這兩個不是一回事，別混著看 |
| AED | 自動體外除顫器。公共場所常見的紅色或黃色急救箱，開機以後跟著語音提示做就行，要不要電擊由它自己判斷 |
| CPR | 心肺復甦。心臟驟停時用力按壓胸口，讓血繼續流動 |
| 3C 認證 | 中國強制性產品認證。列進目錄的那些產品，沒印這個標誌就不准出廠、不准賣 |
| ICP 備案 | 網站或 App 正式上線之前，到工信部的系統裡登記一道手續 |
| 等級保護 | 網絡安全等級保護制度。按一套系統有多重要分成幾個級別，級別越高，要做的安全措施越多 |
| GPL | 一種開源許可證。用了這類代碼做出來的東西，往外發的時候通常也得把自己的代碼一起公開 |
| 競業限制 | 和公司籤的一種約定：離職後一段時間內不去同行的對手那裡上班。這段時間公司要按月給你補償，最長 2 年 |
| 認繳出資 | 註冊公司時承諾要投進去的錢。承諾了就得在法律定的期限內真掏出來，不是寫個數字好看 |
| 定金與訂金 | 兩個詞只差一個字，效力差很多：定金有罰則，收錢的一方反悔要雙倍退還，金額最多為合同額的 20%；訂金只是提前付的錢，反悔沒有這個罰則 |
