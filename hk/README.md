# 生活得更好：香港版

**香港繁體中文 · 本地法規與統計 · 香港例子 · 附官方來源**

[🌐 香港版搜尋網站（啟用 Pages 後）](https://dr-data.github.io/HowToLiveBetter/)　｜　[🖥️ 查看網頁程式碼](index.html)　｜　[報告資料錯誤](https://github.com/dr-data/HowToLiveBetter/issues)

本指南專為香港生活情境編寫。內容以香港適用的法例、公共服務、收費、統計及常見生活決策為主，所有案例均直接使用香港的資料及用語。

首個版本包含 **67 項香港建議及 12 個主題**。內容覆蓋緊急求助、醫療、勞工、綜援、強積金、公屋、詐騙、商業登記、私隱、婚育與香港統計等。每項資料都有：

1. 繁體中文的建議及操作要點。
2. 切合香港生活的實例。
3. 香港官方機構或政府統計資料來源。
4. 最近核對日期。

> **重要：** 本版提供 67 項獨立編寫的香港建議，尚未涵蓋所有生活主題。每條建議以其列出的香港官方來源及適用資格為準，並不自動繼承其他出版物的證據評級。

## 資料來源與更新準則

優先引用香港政府、法定機構、醫管局、勞工處、積金局、房屋委員會、政府統計處、個人資料私隱專員公署及消費者委員會。所有政策必須註明**適用對象、日期、資格及限制**。統計數據必須註明統計年度、單位及口徑，並採用香港適用的資料。

如未找到可核實的香港統計，應明確註明數據暫缺，不要杜撰數字。引用科學研究時，須交代研究對象、樣本及證據限制，讓讀者判斷建議是否適合自己的情況。

## 使用搜尋網站

截至 2026 年 10 月 18 日，此儲存庫的 GitHub Pages 尚未啟用。要讓其他人直接使用搜尋網站，請在 GitHub 開啟此儲存庫的 **Settings → Pages**，於 **Build and deployment** 選擇 **Deploy from a branch**，設定 **main** 及 **/(root)**，然後儲存。

啟用後，香港版入口應為 **https://dr-data.github.io/HowToLiveBetter/**，預設顯示香港繁體中文。請留意部署網址以 GitHub Pages 設定頁實際提供者為準。

亦可在本地用下列命令預覽（不須安裝網站依賴）：

```bash
git clone https://github.com/dr-data/HowToLiveBetter.git
cd HowToLiveBetter
python -m http.server 8000
```

然後在瀏覽器開啟 `http://localhost:8000/`。直接雙擊 `hk/index.html` 可能因瀏覽器限制而無法讀取 `data.json`。

## 維護內容

唯一資料來源是 [data.json](data.json)。如更新數據或修訂文字：

```bash
node hk/build.mjs
node hk/build.mjs --check
```

這會從 JSON 重新建立本目錄的 12 個 Markdown 章節，並確認內容和資料格式一致。靜態網站 [index.html](index.html) 會直接讀取 JSON，因此毋須額外編譯。

**本儲存庫不使用 GitHub Actions。** 更新與驗證需手動執行上述指令，提交檔案後即可供 GitHub 閱讀。如需要 EPUB、PDF 或其他衍生格式，請在本地使用適當建置工具，並自行發布。GitHub Pages 可選擇直接從 `main` 分支根目錄部署，毋須設定 Actions workflow。
