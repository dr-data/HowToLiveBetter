# 香港通用生活指南：34 個主題

這是 **765 項香港繁體中文通用生活建議**，已將案例改寫為可在香港生活中理解的情境。其中 **520 項已完成第二輪通用化文字審校**，另外 **245 項仍須核對香港適用的醫療、法律、福利、金融或行政規則**。全部均屬教育性草稿，尚未完成逐項專家核證。

目前整理為 34 章，亦記錄了每項的審校狀態。另有 [67 項較具體的香港專題建議](../README.md)，兩組內容分開保存，避免把未審核的一般原則當作已核證的本地政策。

> **審核說明：** 這 765 項並非逐項完成醫學、法律、財務或公共政策查核。條目中的官方連結是延伸查閱入口，並非每一條說法已經得到該機構的直接核證。準備實際採取行動前，請核對現行官方資訊。

## 編輯準則

1. 以可獨立閱讀的**一般原則**為主，不把其他地區的法律、服務、補貼及金額搬到香港。原始章節中帶有地區限制的條目不直接視為香港適用。
2. 案例使用香港生活場景及繁體中文；沒有可靠統計時不提供具體效果數字。
3. 涉及醫療、急救、法律、勞工、金融、教育入學及公共服務時，清楚標示專業核對需求。
4. 整理原章節對應索引以方便維護，但不把原著中的外地例子放進香港正文。
5. 來源及資格應定期覆核；未完成獨立核證前，不得標記為「已驗證」。

## 版本與手動操作

[通用化條目資料集](catalog.json) 是香港版 34 章的唯一正式資料來源。編輯後在本機執行：

```bash
node hk/general/build.mjs
node hk/general/build.mjs --check
```

此操作不會呼叫 GitHub Actions，亦不會自動發行電子書。原始專題版本的香港資料在 `hk/data.json`，可另外執行 `node hk/build.mjs --check`。
