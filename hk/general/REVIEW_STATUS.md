## 編輯原則

1. 保留不依賴特定法例或地區制度的生活原則，使用地道香港繁體中文。
2. 對通用建議補充容易理解的香港生活情境，不加入無來源的統計或效果數字。
3. 法律、醫療、勞工、福利、稅務及入境規定須逐項核對，未完成前保留清楚的警示。
4. 官方連結僅供延伸查閱，不代表主管部門為每條建議背書。只有具體、對應的來源才可以支持具體數值及政策要求。
5. 香港專題正文另見 [67 項本地條目](../README.md)，與通用草稿分開。

## 手動維護

維護正式資料集 `catalog.json`，再於本機執行：

```bash
node hk/general/build.mjs
node hk/general/build.mjs --check
```

**不使用 GitHub Actions。** 原始資料另行保留，以便核實來源和追蹤修訂。`part` 和 `audit` JSON 檔是文字審查的工作紀錄，不是網站的另一份正式目錄。
